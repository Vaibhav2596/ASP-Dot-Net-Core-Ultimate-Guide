# ASP.NET Core — HTTP Response

## Response Start Line

The **Response Start Line** includes:

* **HTTP Version**
* **Status Code**
* **Status Description**

---

### HTTP Version

```
1.1 | 2 | 3
```

---

### Status Code

```
101 | 200 | 302
400 | 401 | 404 | 500
```

---

### Status Description

```
101 → Switching Protocols
200 → OK
302 → Found
400 → Bad Request
401 → Unauthorized
404 → Not Found
500 → Internal Server Error
```
