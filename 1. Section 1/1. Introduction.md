
## What is Asp.Net Core ?

1. Asp.Net Core is a cross-platform, high-performance, open-source framework for building modern, cloud-enabled web applications and services.


## Features of Asp.Net Core

1. Cross-platform 
   Asp.Net Core apps can be hosted on Windows, LINUX and Mac.

2. Can be hosted on different servers
   Supports Kestrel, IIS, Nginx, Docker, Apache

3. Open Source
   Contributed by over 1000+ contributors on GitHub

4. Cloud-enabled
   Out-of-box support for Microsoft Azure

# Major Parts of Asp.Net Core

1. Asp.Net Core MVC 
    For Creating medium to complex web applications

2. Asp.Net Core Web API
    For Creating RESTful services for all types of client applications.

3. Asp.Net Core Razor Pages
    For Creating simple & page-focused web applications

4. Asp.Net Core Blazor
    For Creating web applications with C# code both on client-side and server-side


Out of all 4 the first two Asp.Net Core MVC and Asp.Net Core Web API are mainly used for Development


### Prerequisites

1. C#
    Classes, Interfaces, Inheritance, async/await, Extension Methods, Lambda Expressions etc.

2. HTML, CSS, JavaScript, jQuery
    Intermediate Level
