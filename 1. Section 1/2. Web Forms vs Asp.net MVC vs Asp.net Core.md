

## Asp.Net Web Forms vs Asp.Net MVC vs Asp.Net Core

1. Asp.Net Web Forms (2002) - Windows Only - Not Cloud Friendly - Not Open Source

    ### Follows Event Driven Development Model.

    Performance issues due to server events and view-state
    Tries to make Web as Stateful instead of Stateless

    So if you talk about ASP.Net Web Forms, mainly it has the performance drawbacks.
    It offers slower performance due to server events and Viewstate because ASP.Net Web Forms itself tries to make the web as stateful instead of stateless.

    That means every page has to store its state, and that state will be stored in the form of Viewstate state, and that Viewstate object has to be transferred from the client to server and server to client for each request.

2. Asp.Net MVC (2009) - Windows Only - Slightly Cloud Friendly - Open Source

    ### Follows Model View Controller (MVC) pattern.

    Performance issues due to some dependencies with asp.net (.net framework).

    ASP.Net MVC uses model view and controller pattern.That means it offers clean separation of concerns so that you can test your models, views and controllers independently.So you can unit test your controllers, models and views.

    But it has its own drawback because ASP.Net MVC is built on top of some of the components that are already developed for ASP.Net Web Forms earlier.

    For example System.web. So somewhere it offers slower performance partially and lack of support for cross platform.That means it is quite difficult or impossible to host your ASP.Net MVC applications on other operating systems other than windows.

    Because ASP.Net MVC being a part of dotnet framework, or at least it is tightly coupled with some of the components of dotnet framework internally, it makes it problematic to host on other operating systems.

3. Asp.Net Core (2016) - Cross Platform - Cloud Friendly - Open Source

    ### Follows Model View Controller (MVC) pattern.

    Faster Performance

    ASP.Net Web Forms follow event driven programming approach.For example, if the user clicks on a button, it offers click event on the server, but ASP.Net MVC and ASP.Net core supports model view controller pattern.

    In addition to this, you can add dependency injection pattern optionally in ASP.Net MVC, but ASP.Net core has built in support for Dependency Injection.

    In addition to this, ASP.Net core is highly unit testable and also a modular framework.
    ASP.Net Web Forms is no longer an option for active development, and anytime soon Microsoft can drop the support for ASP.Net MVC in the near future.

    So that says ASP.Net core is the future of web development with DotNet.
