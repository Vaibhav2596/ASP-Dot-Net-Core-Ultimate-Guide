## LaunchSettings

1. By Default Asp Dot Net Core Web App Uses Kestrel Server By Default.
2. We Can use IISExpress to simulate Reverse Proxy Server we can make the changes in launchsettings.json file.
3. To Locate LaunchSettings file go to MyFirstApp > Properties > launchSettings.json.


```csharp
  "profiles": {
    "http": {
      "commandName": "Project",
      "dotnetRunMessages": true,
      "launchBrowser": true,
      "applicationUrl": "http://localhost:5259",
      "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development"
      }
    }
  }

```

4. commandName Project means you tend to use Kestrel only.
5. dotnetRunMessages to use dot net command inside your terminal choose either true or false.
6. Application Url You are free to give any other port number which is greater than 1024 and less than 65536 because all the ports number less than 1024 are reserved by Windows Operating System.
7. The environment variables are the artifacts that contains the global values that are available across the entire application.
8. IIS - Internet Information Services.



The IIS Express is the lightweight version of the actual server that is IIS.
Both IIS Express and IIS also support additional features which are not supported by Kestrel.

For example, HTTP access logs, portsharing, Windows authentication,
process activation, configuration API,etc.
