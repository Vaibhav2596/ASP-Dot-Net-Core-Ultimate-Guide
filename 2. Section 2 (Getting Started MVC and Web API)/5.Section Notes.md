# Explanation of the Code in Detail

```csharp
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello World!");

app.Run();
```

---

## builder Creation

```csharp
var builder = WebApplication.CreateBuilder(args);
```

### Purpose

Initializes a new instance of the **WebApplicationBuilder** class.

### Details

`WebApplication.CreateBuilder(args)`:

* Static method that initializes WebApplicationBuilder
* `args` represents command line arguments

### Builder Configures

**Configuration**

Reads configuration settings from:

* appsettings.json
* environment variables

**Logging**

Configures default logging services.

**Dependency Injection**

Registers services for dependency injection.

---

## Building the App

```csharp
var app = builder.Build();
```

### Purpose

Builds the **WebApplication** instance.

### Details

* Finalizes application configuration
* Compiles middleware components
* Creates the WebApplication object to handle HTTP requests.

---

## Mapping GET Request

```csharp
app.MapGet("/", () => "Hello World!");
```

### Purpose

Maps **HTTP GET requests** to the root URL.

### Details

`app.MapGet`

Defines a route for GET requests.

`"/"`

Represents the root URL.

`(() => "Hello World!")`

Lambda expression returning the response.

The response body will contain:

```
Hello World!
```

---

## Running the Application

```csharp
app.Run();
```

### Purpose

Runs the application.

### Details

* Starts the **Kestrel web server**
* Listens for HTTP requests
* Blocking call
* Runs until manually stopped

Example stop:

```
Ctrl + C
```

---

# Summary

The code creates a **minimal ASP.NET Core web application**.

| Step              | Description             |
| ----------------- | ----------------------- |
| `CreateBuilder()` | Configures app settings |
| `Build()`         | Builds the application  |
| `MapGet()`        | Maps route              |
| `Run()`           | Starts web server       |

# Kestrel Server and Reverse Proxy Servers

---

## Kestrel Server

### Overview

Kestrel is the **cross platform web server** for ASP.NET Core.

It is **lightweight and fast**.

### Responsibilities

* HTTP request handling
* Hosting ASP.NET Core apps
* Server configuration

Supports:

* HTTP
* HTTP/2
* HTTPS

### Use Case

Ideal for:

* Development
* Internal networks

Usually used **behind a reverse proxy in production**.

---

# Reverse Proxy Servers

### Overview

A reverse proxy server **forwards client requests to backend servers**.

Common reverse proxies:

* Nginx
* Apache
* IIS

---

### Responsibilities

**Load Balancing**

Distributes requests across multiple servers.

**SSL Termination**

Handles SSL encryption and decryption.

**Caching**

Caches responses to improve performance.

**Security**

Provides:

* Request filtering
* IP whitelisting
* Rate limiting

---

### Use Case

Placed **in front of Kestrel** to improve:

* security
* scalability
* performance

---

# Responsibilities of Kestrel and Reverse Proxy

## Kestrel

* Serves HTTP requests
* Efficient request processing
* Should run behind reverse proxy in production

---

## Reverse Proxy

* Acts as intermediary
* Provides SSL termination
* Provides load balancing
* Adds security layer

# Detailed Notes for launchSettings.json

`launchSettings.json` is a configuration file used to **define how the application launches during development**.

It defines:

* environment
* URLs
* debugging settings

---

# Structure of launchSettings.json

---

## $schema

Specifies schema URL for validation and IntelliSense.

```
"$schema": "http://json.schemastore.org/launchsettings.json"
```

---

## iisSettings

Configures **IIS Express settings**.

```json
"iisSettings": {
  "windowsAuthentication": false,
  "anonymousAuthentication": true,
  "iisExpress": {
    "applicationUrl": "http://localhost:19872",
    "sslPort": 0
  }
}
```

### Properties

**windowsAuthentication**

Enables Windows Authentication.

**anonymousAuthentication**

Allows anonymous users.

**iisExpress**

`applicationUrl`

URL when running with IIS Express.

`sslPort`

HTTPS port.

`0` means HTTPS disabled.

---

# Profiles Section

Profiles define **different ways to run the application**.

```json
"profiles": {
  "http": {
    "commandName": "Project",
    "dotnetRunMessages": true,
    "launchBrowser": true,
    "applicationUrl": "http://localhost:5117",
    "environmentVariables": {
      "ASPNETCORE_ENVIRONMENT": "Development"
    }
  },
  "IIS Express": {
    "commandName": "IISExpress",
    "launchBrowser": true,
    "environmentVariables": {
      "ASPNETCORE_ENVIRONMENT": "Development"
    }
  }
}
```

---

# http Profile

| Setting              | Meaning                     |
| -------------------- | --------------------------- |
| commandName          | Uses `dotnet run`           |
| dotnetRunMessages    | Shows detailed messages     |
| launchBrowser        | Opens browser automatically |
| applicationUrl       | Application URL             |
| environmentVariables | Environment settings        |

Environment variable:

```
ASPNETCORE_ENVIRONMENT = Development
```

---

# IIS Express Profile

| Setting              | Meaning                   |
| -------------------- | ------------------------- |
| commandName          | Uses IIS Express          |
| launchBrowser        | Opens browser             |
| environmentVariables | Environment configuration |
