## Creating First ASP .Net Core Application

1. Open Visual Studio
2. File > New > Project
3. Filter Using C#, Windows, Web
4. Choose template as ASP.NET Core Empty
5. Project Name - MyFirstApp
6. Choose Framework - .NET 10
7. Uncheck Configure for HTTPS

## Understanding File Structure

1. Program.cs - Entry Point of the Application that means the execution starts from the Program.cs file 

```csharp

var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

app.MapGet("/", () => "Hello World!");

app.Run();


```
